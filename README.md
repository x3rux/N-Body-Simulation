# N-Body Simulation in C

A gravitational N-body simulation project built from scratch in C using [raylib](https://www.raylib.com/) for visualization.

## Current Status
- Setup environment (GCC C11, GNU Make, raylib on Windows).
- Phase 0: 2D and 3D raylib mechanics, camera controls, and basic numerical integration sandboxes.

## Build & Run

Requires GCC with C11 support, Make, and raylib.

```bash
# 2D bouncing ball sandbox
make 2d

# 3D bounding box & camera sandbox
make 3d
```
